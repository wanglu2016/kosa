# 文件格式與語義

所有 `.kosa` 文件：非縮進行是條目首行；以一個全角空格「　」縮進的行是該條目的欄（「欄名：內容」）；縮進兩個全角空格是上一欄的續行；`#` 開頭是註釋。命題一律用繁體（要與 CBETA 逐字比對）。

## 一、本體 `本體/`

### 門.kosa —— 分別的維度（劃分）

```
門 性：善、不善、有覆無記、無覆無記
門 見種〔慧〕：身見、邊見、……、非見          ← 〔適用類〕：只有慧才在此門取值
門 表非表〔色處或聲處〕：身表〔色處〕、語表〔聲處〕、非表   ← 值也可帶適用類
論域 有情                                     ← 此行之後的門用於有情
門 果位：異生、預流向、……
```

- 一門是一個劃分：值互斥、在適用類上窮盡。這些不再是隱含的：每門自動生成本體結構條目
  「X・互斥」「X・窮盡」「X・適用」（有適用類時）、「值・適用」（值帶適用類時）。
- 門值是**原始概念**（自性）。按某標準歸成的類（惑、五見、大地法、四諦）寫成定義，不立門。
- 門值名要長一點、不易混：不要用單字（「行」「生」「苦」會在分詞時吞掉別的詞），例如十六行相寫成「非常行相」「苦行相」。全庫的詞不能重名（定義、門值、門名、關係名、謂詞名共用一個詞表）。

### 定義.kosa —— 由門值組成的類

```
定義 染：不善或有覆無記
別名 無明＝癡
```

類表達式：「・」且、「或」或、「非」非（「非」只管緊跟的一個詞）。定義的論域由其中的詞推出。
定義是名目，總是生效（判定、結構計算時）；只在檢驗「依」時，只開「依」中〔本體：…〕列出的定義。

### 關係.kosa

```
關係 相應（心心所，心心所）〔對稱〕
關係 同所依（心心所，心心所）〔對稱、傳遞〕
```

自動生成本體結構條目「R・類型」（兩項各屬其類、且不自反）、「R・對稱」「R・傳遞」。兩項的類可以屬不同論域：

```
關係 成就（有情，法）        ← 頌「得謂獲成就，非得此相違」；公式中寫 成就(p，x)
```

### 地：繫與依地（v0.6）

有漏法的地用「繫不繫」門；無漏有為法不繫，另立「依地」門（適用類 `無漏・有為`，九值：無漏未至、無漏靜慮中間、無漏初靜慮……無漏無所有處；頌「道展轉九地」）。
九地是定義：`初靜慮地：初靜慮繫或無漏未至或無漏靜慮中間或無漏初靜慮`，`第二靜慮地：第二靜慮繫或無漏第二靜慮`……，`非想非非想處地：非想非非想處繫`（有頂無無漏）。
問「某地有沒有某法」一律用「X地」，不用「X繫」（讀法凡例讀十七）。

## 二、命題庫 `庫/`

`論域.kosa` 聲明類別（`類 法：開放 5`、`類 有情：開放 2`）、預設類、謂詞（未立為門的性質）、品的次序。各品一個文件。

### 條目的欄

| 欄 | 意義 |
|---|---|
| （首行） | 【編號】命題。 |
| 標題 | 給人看的一句話。 |
| 頌 | 直接出處的頌文，逐字；多句用「；」分隔。機器核對 CBETA。 |
| 相關頌 | 相關而非直接出處的頌。也核對。 |
| 出處 | 頌以外的出處：《俱舍萬字》段號（如 1.1.11）、《俱舍九題》頁碼、論名卷數。 |
| 依據 | 論文引文等。 |
| 依 | 可選。編者擬的推導：所依條目，及〔本體：定義、結構條目〕。機器檢驗推得出、缺一不可。 |
| 詮釋 | 形式化時做的、原文沒有明說的決定（讀法的取捨）。 |
| 說明 | 給人看的解釋。 |
| 狀態 | 只寫「待核」：形式化時把握不足（不是「沒找到明文」的意思）。 |
| 性質 | 「約定」：由名目成立的條目（結構計算中偏好留作施設）。 |
| 原編號 | 舊版編號。 |

### 句式（全部會編譯成一階公式）

| 句式 | 意義 |
|---|---|
| `A 唯 B`（皆、是、定） | 凡 A 皆 B |
| `A 非 B`（不容） | 凡 A 皆非 B |
| `A 即 B` | A 與 B 範圍相同 |
| `A 通 B、C` | 凡 A 或 B 或 C，且有 A 是 B、有 A 是 C |
| `A 容 B` | 有 A 是 B |
| `A 容有` / `A 無` | 有 A / 沒有 A |
| `A：B、C` | A 即「B 或 C」 |
| `B、C、D 互斥` | 兩兩不相容 |
| 公式 | `凡 x、y：…`、`有 z：…`、且、或、非、⇒、⇔、＝、≠；`類(x)`、`關係(x，y)`、`門(x)＝門(y)`、`門(x)＝值`、`［類表達式］(x)`；`凡 p 有情：…` 標明論域 |

類名「法」「有情」可作類用（`一切法` 是「法」的別名）。

## 三、題庫 `題庫/`

```
題庫 九題・第二題：業在蘊處界中是何所攝
引 庫

【2.1·身表】身表 唯 色蘊・色處
　題：例題2.1之1：身表業是何所攝？答：色蘊、色處、色界
　答：成立            ← 書中答案：成立／有／可能 → 應證成；不成立／無／不可能 → 應證否
　出處：《俱舍九題》頁 49
```

比對結果：一致、未決（庫沒覆蓋到，不算錯）、相違（必須處理）。

題目可以是公式，跨論域時尤其如此（`題庫/三道題.kosa`）：

```
【三乙·生無色界】有 p、x：生空無邊處(p) 且 樂根(x) 且 成就(p，x)
　答：有
```

出題時把一個問題拆成「題網」：對一個分類的每一項各出一條（五蘊＋十二處＋十八界逐一問「有沒有律儀」，九地逐一問「有沒有樂受」）。題網既是答案的嚴格形式，也量出庫的完備性。

## 四、模組 `模組/`

模組四、五、六只寫 `引 庫`、`目標 編號`、`旁證 編號、編號`。模組一、二、三是 v0.1 的演示，自帶前提和類別（固定類別、積類別），走舊的編碼（門結構內建），不要用命題庫的寫法改它們。

## 五、引擎的語義（改引擎前要懂）

- 命題庫模式（`引 庫`）：每個開放類別取若干元素槽；門值、關係自由選取；本體結構條目各有開關（`on(k)`），判定與結構計算時全開，檢驗「依」時只開列出的。
- 判定 `judge`：證成＝全庫 ⊨ P；證否＝全庫 ∧ P 無模型；兩者皆否＝未決（附實例、反例）。
- 結構 `structure.analyze`：核心＝不能由其餘全部條目推出（附反例）；按偏好貪心選施設；推出者用二分法求極小前提（`Engine.minimize`）。
- 「推得出」在有界世界中具傳遞性，所以貪心刪去的條目都能由最後的施設推出。
